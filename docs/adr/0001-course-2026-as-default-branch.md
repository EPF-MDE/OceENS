# `course-2026` becomes the default branch for the semester

For the 2026–27 *Complex Web Services* course, about twenty students fork OcéEns and fork
the default branch: `course-2026` therefore becomes the repository's default branch, the
branch forks start from and the branch pull requests target (including the dev sign-in,
#82, and the per-role seed, #84). `main` is left untouched during the semester, to give
students a stable base and to keep course-specific code out of it; no `main` →
`course-2026` synchronisation is planned before the end of the semester.
